# Standards

We advocate treating verified QOSS contributions as a form of research publication on
equal footing with journal articles. The standards below help contributors explain
their scientific contribution and provide reproducible evidence, with clear attribution
and a citable software version.

Policy templates that QOSS projects can copy and adapt.

- [ai-contribution-policy.md](ai-contribution-policy.md): what every contribution must
  state, plus disclosure and review rules for AI-assisted contributions.
- [agent-boundaries.md](agent-boundaries.md): limits on an automated contributor, and
  where each one is enforced outside the agent's control.
- [agents-md-template.md](agents-md-template.md): a starting point for a repository's
  AGENTS.md file.
- [ci-gates.md](ci-gates.md): checks a repository can enforce mechanically.
- [contributor-pipeline.md](contributor-pipeline.md): practices for projects and event
  organizers who recruit maintainers from their contributors.
