# Contributing

Contributions are welcome from anyone in or around the quantum open-source software
community. This project follows the
[Unitary Foundation code of conduct](https://github.com/unitaryfoundation/unitary.foundation/blob/main/CODE_OF_CONDUCT.md).

## Ground rules

1. **Disclose AI involvement.** This repository follows its own
   [AI contribution policy](standards/ai-contribution-policy.md): state in the pull
   request whether and how AI tools were used. AI-assisted contributions are welcome as
   long as they are disclosed. The same applies to us, and
   [AI_use_this_repository.md](AI_use_this_repository.md) is our own statement.
2. **Date what you touch.** Every content page carries a `Last verified:` line. Update it
   when you have actually checked the content, and only then.
3. **Small pull requests.** One card, one catalog entry, or one policy change per PR.
4. **Claims need sources.** Tool entries and factual statements link to the tool's
   repository, paper, or documentation. If a claim cannot be verified, leave it out.

## What to contribute

- A harness card for a workflow you have actually run ([template](harnesses/TEMPLATE.md)).
- A verifier catalog entry, or a correction to scope, cost, or maturity of an existing one.
- A gap: if you looked for a tool or a practice and it did not exist, record that in the
  relevant directory's README. Gaps drive the roadmap.
- Benchmark tasks from real, resolved QOSS work.

## Process

Open an issue for discussion, or a pull request directly for small changes. Maintainers
for each directory are listed in the top-level README; they review within the disclosure
rules above.
