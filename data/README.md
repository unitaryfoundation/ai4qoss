# Data

Outputs of the community analyses behind the forthcoming perspective paper: hackathon
statistics, model-staleness results, API churn measurements, and similar.

## Status

No datasets published yet. Planned, subject to consent review:

- unitaryHack per-edition statistics (submissions, merge rates, review indicators),
  aggregated.
- Contributor retention curves, aggregated and anonymized.
- Model staleness results: current models writing against current framework APIs,
  deprecated-usage counts, with the harness used to produce them.
- API churn measurements for major quantum frameworks against mainstream baselines.

## Privacy

Nothing individual-level is published. Anything derived from participant data is
aggregated, and released only after consent review. Each dataset ships with a note
stating its source, processing steps, and limitations.
